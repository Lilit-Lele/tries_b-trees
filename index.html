      How the counters work

      • B-tree word comparisons count each time the search word is compared against a key in a node. Nodes are scanned left to right, stopping at the first key that is equal or larger.
      • B-tree character checks count the letters examined inside those word comparisons. Comparing cart with care checks 4 letters before the difference shows up.
      • Trie character checks count one check per letter of the search word, since each node finds its child by letter directly. The final end-of-word flag test is not counted.
      • Green in the history table marks the lower of the two character-check totals for each lookup. Changing the B-tree degree rebuilds it from the same words, in the same insertion order.
